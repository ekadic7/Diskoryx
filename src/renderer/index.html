Info: how duplicate analysis works

Choose a local drive. User files excludes Windows, Program Files, ProgramData, AppData, the Recycle Bin and System Volume Information. Choose Entire drive to include them. A completed full-drive scan is reused without scanning directories again; otherwise a full inventory is needed. Analysis filters by size, compares small samples, then reads candidate file contents fully to confirm matches. Windows may download online-only cloud files. No files are changed or deleted.

Matching contents can have different names. Windows Installer caches and application files may be required. Logical bytes in extra copies are not an estimate of physical disk space freed.

Identical contents do not mean a file is safe to remove.

Action history

Recent file actions, saved only on this device. Restore never overwrites an existing item.

How restore and Undo work

Restore from Recycle Bin finds the exact item deleted by Diskoryx. Undo copy recycles only an unchanged copy; the original stays intact. Redo copy makes a fresh copy from the current original. Move records offer Return to original location and Redo move; changed items or parents are refused. Up to 500 actions are retained.
